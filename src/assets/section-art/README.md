# Section artwork

Generated with the built-in ImageGen tool for the approved Nitrutsav Events and FAQ refresh.

- events-paper.png: original festival poster-wall paper artwork (1122 × 1402).
- faq-textile.png: original Sambalpuri-inspired textile frame (1024 × 1536).
- paper-divider.png: original transparent printed torn-paper separator.

Matching .webp files are optimized delivery copies encoded with Sharp at quality 88. Original PNGs are retained. The site imports WebP versions only.

Exact prompts are saved in events-prompt.txt, faq-prompt.txt and divider-prompt.txt. CSS controls layout, opacity and motion; the original artwork is unmodified.
